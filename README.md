# Network Intrusion Detection System

This project implements a Machine Learning based Intrusion Detection System using the NSL-KDD dataset.

## Features
- Data preprocessing
- One-hot encoding
- Standard scaling
- SMOTE for class imbalance
- Hyperparameter tuning
- Multiple ML models:
  - Random Forest
  - SVM
  - KNN
  - Decision Tree
- Evaluation using:
  - Accuracy
  - Precision
  - Recall
  - F1-score
  - Confusion Matrix

## Dataset
NSL-KDD Dataset

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn
